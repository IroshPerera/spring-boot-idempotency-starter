# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| 0.1.x | Yes |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

If you find a security issue, please contact the maintainer privately through the GitHub profile:

https://github.com/IroshPerera

Please include:

- A clear description of the vulnerability
- Steps to reproduce the issue
- Affected version
- Potential impact
- Suggested fix, if available

Please do not publicly disclose the vulnerability until it has been reviewed and addressed.
